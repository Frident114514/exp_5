## 记录方式

重要技术或产品选择每项写一个 Markdown 文件，例如 `0001-tech-stack.md`。先记录问题、选项和原因，再将状态改为“已决定”。

```markdown
# 0001 决策标题

- 日期：YYYY-MM-DD
- 状态：待讨论 / 已决定 / 已替代
- 参与人：
- 背景与问题：
- 候选方案：
- 最终选择与原因：
- 对代码、接口、测试和交付的影响：
```

已决定的方案发生变化时，新建记录并注明被替代的旧记录，避免只改结论而丢失原因。
