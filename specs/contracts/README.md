# 接口与数据约定

本目录存放小程序、后台和服务端共同遵循的契约。开始跨端实现前，先确定这些内容：

1. 身份认证方式、用户和管理员权限。
2. API 路径、方法、请求参数、成功响应、错误码和分页格式。
3. 动态、媒体、标签、评分、评论等字段及校验规则。
4. 上传文件类型和大小限制、文件访问方式、删除规则。

接口增多时，可继续按模块拆分文档。新增接口的文档模板：

```markdown
## 接口名称
- 需求编号：U00
- 方法与路径：GET /api/example
- 权限：登录用户 / 管理员 / 公开
- 请求参数：名称、类型、必填、说明
- 成功响应：字段、类型、说明
- 失败响应：HTTP 状态、业务错误码、触发条件
- 验收样例：请求和响应示例
```

改动契约时，同步更新调用方和 `../tasks.md` 中受影响任务。接口命名、字段及示例数据是开发约定，不能直接当作已完成实现。
