# M05 账号界面手工用例清单（微信开发者工具）

用途：S3 要求"在微信开发者工具手工检查页面行为并执行账号界面用例"。自动化测试只能证明逻辑正确，**页面实际表现必须在这里点一遍并留证**。

## 前置条件

1. 在 `src/miniapp/` 执行 `npm run dev:mp-weixin`（或让我重新 `build:mp-weixin`），产物目录 `dist/dev/mp-weixin`（或 `dist/build/mp-weixin`）。
2. 微信开发者工具导入该目录；AppID 选「无 AppID / 测试号」。
3. 「详情 → 本地设置」勾选**不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**。
4. 确认首页「运行环境 → 模拟接口」显示 **已开启（本地样例数据）**；没有的话让 M05 检查 `.env.local` 后重新编译。
5. 可用账号：`demo / demo1234`（普通用户）、`admin / admin1234`（管理员）。

> 模拟接口说明：数据在内存中，**重启编译即恢复初始状态**（改过的密码、新注册的账号都会消失）；媒体地址没有真实文件，图片会加载失败，这是预期行为。

## 记录方式

- 每项执行后在「实际结果」写**通过 / 失败 + 现象**，失败要写复现步骤。
- 截图建议放 `tests/evidence/M05/screenshots/`，命名 `C01-1-注册校验.png` 这种格式，并把文件名填到「证据」列。
- 失败项修复后重新执行，保留首次失败记录。
