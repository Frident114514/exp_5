## 新增实现与结果

| 范围 | 验证结果 |
| --- | --- |
| 改密 | 错误原密码 401、非法/相同新密码 400；有效修改 200；旧密码与旧令牌失效，新密码登录成功；令牌版本只加 1 |
| 并发与准入 | 同一旧版本同时改密仅一次成功、另一次 401；密码名额占满返回 429，释放后恢复；未登录拒绝 |
| 管理员初始化 | 测试脚本通过环境变量创建合成管理员；重复初始化不重置密码，不将同名普通用户提升为管理员 |
| 用户查询 | 账号关键词、字面 % 搜索、倒序分页、总数、状态和时间字段正确，不泄露密码哈希；非法/超大页码、每页条数及超长关键词 400 |
| 禁用 | 普通用户 403、匿名 401、自身或其他 ADMIN 403、不存在 404；合法禁用 200，登录/旧令牌立即拒绝，重复请求仅 1 条审计、版本只加 1 |
| 事务回滚 | 同步 UserDisabled 监听器写入数据库后抛错，用户状态、版本、监听器写入与审计全部回滚；失效管理员版本不能继续操作 |
| 既有回归 | 注册、登录、JWT、实时状态/角色、密码预算隔离、有界等待与诊断测试通过 |
