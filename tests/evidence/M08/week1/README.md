## 复现与页面检查

在仓库根目录执行以下命令；本机默认 Node 12 时先切换到已安装的 Node 22：

```sh
export PATH=/Users/yth/.nvm/versions/node/v22.23.1/bin:$PATH
cd src/admin-web
npm ci
npm run format:check
npm run lint
npm run build
npm test -- --reporter=default --reporter=json --outputFile.json=../../tests/evidence/M08/week1/test-results.json
npm run dev:demo
```

打开 `http://127.0.0.1:5173`，使用管理员 `demo_admin` / `demo1234` 检查两类查询页面；普通用户为 `demo_user`，密码同上。输入不存在的关键词查看空结果，输入 `请求失败` 查看失败提示。所有演示账号、令牌与记录均为虚构。

真实服务联调改用 `npm run dev`，配置与 M01 待确认字段见 [管理员后台 README](../../../../src/admin-web/README.md)。
