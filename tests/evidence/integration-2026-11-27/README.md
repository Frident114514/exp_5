## 发现并修复的问题

1. 默认 H5 从 5173 直接访问 8080，注册请求被浏览器跨域限制阻止；后端接口正常，预检请求返回 401。增加 Vite `/api` 开发代理，H5 未显式配置 API 地址时使用 `/api/v1`。微信小程序仍使用原有绝对地址。显式配置地址时以环境变量为准。
2. M07 client 已拼接 API 基础地址，统一请求层在同源相对地址模式下又追加一次前缀，导致广场 404。增加 `resolvedUrl` 标记，让 client 已拼好的地址保持原样；M06 端点相对地址仍由统一层拼接。
3. 增加自动回归用例，检查 H5 广场最终请求为 `/api/v1/posts?page=1&pageSize=10`，不能重复前缀。

## 运行说明与范围

先启动真实后端，再在 `src/miniapp` 执行 `pnpm dev:h5`。默认开发代理转发到 `http://127.0.0.1:8080`，可用 `VITE_DEV_API_TARGET` 修改。此代理仅供 Vite 开发服务；生产 H5 需由部署服务器配置同源反向代理，或配置允许访问的完整 API 地址。
