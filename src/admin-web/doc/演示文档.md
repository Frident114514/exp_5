# 管理员后台第一周演示

负责人：叶天豪（M08）。本周实现管理员登录、用户查询、动态组合查询、分页及请求状态反馈。

## 启动

使用 Node.js 22.12+，在 `admin-web` 目录执行：

```sh
npm ci
npm run dev:demo
```

打开 `http://127.0.0.1:5173`。

| 账号         | 密码       | 用途                     |
| ------------ | ---------- | ------------------------ |
| `demo_admin` | `demo1234` | 管理员登录与查询         |
| `demo_user`  | `demo1234` | 演示普通用户无法进入后台 |

演示模式使用浏览器内的虚构数据，不请求真实后台或数据库。

## 演示步骤

1. 未登录直接打开 `/users`，页面跳转到登录页。
2. 使用普通用户或错误密码登录，查看失败提示；使用管理员账号进入后台。
3. 在用户管理页按账号或昵称查询，演示翻页、改变每页条数和重置。
4. 在动态管理页按关键词、作者 ID、标签和日期组合筛选；开始日期晚于结束日期时显示提示。
5. 输入不存在的关键词查看空结果；输入 `请求失败` 查看失败提示与重试按钮。
6. 点击退出，再访问管理页面时返回登录页。

## 接口列表

以下为前端已接入的四个接口，基础路径为 `/api/v1`。

| 方法 | 路径           | 请求参数                                                       | 返回内容                                         |
| ---- | -------------- | -------------------------------------------------------------- | ------------------------------------------------ |
| POST | `/auth/login`  | JSON：`account`、`password`                                    | `accessToken`、`expiresAt`、`user`               |
| GET  | `/users/me`    | 无                                                             | 当前账号、昵称、角色等身份信息                   |
| GET  | `/admin/users` | `keyword`、`page`、`pageSize`                                  | 用户列表：ID、账号、昵称、角色、状态、创建时间   |
| GET  | `/admin/posts` | `keyword`、`authorId`、`tag`、`from`、`to`、`page`、`pageSize` | 动态列表：作者、正文、媒体、标签、时间、评分摘要 |

- 登录公开；其他请求携带 `Authorization: Bearer <accessToken>`，管理接口仅管理员可访问。
- 统一响应为 `{ code, data, message }`；分页数据为 `{ items, page, pageSize, total }`，页码从 1 开始。
- 日期为 `YYYY-MM-DD`，按北京时间自然日解释，包含起止日。401 返回登录，403 显示无权限。
