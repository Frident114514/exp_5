## 2. 页面结构

### 广场 `pages/square/index`

```
┌─ 标题区：动态广场 / 公开浏览 · 按发布时间倒序 / 共 N 条 ─┐
│ 首次加载：骨架屏 ×3                                     │
│ 失败：⚠ 加载失败 + 具体原因 + [重新加载]                │
│ 空：🗒 还没有动态 + [刷新试试]                          │
│ 列表：FeedPostCard × N（点按 → 详情）                       │
│ 底部：加载更多中 / 加载失败点击重试 / 没有更多了        │
└──────────────────────────────────────────────────────────┘
```

### 详情 `pages/detail/index`

```
作者首字头像 · 昵称 · 发布时间（YYYY-MM-DD HH:mm） · #id
正文（可选中复制）
媒体占位（1 张=大图位，2 张=双列，3 张以上=三列 + 剩余数量）
标签区（无标签时显示“未添加标签”）
评分摘要卡（星级 · 平均分 · 人数；无评分显示“暂无评分”，标注“后续阶段开放”）
底部：内容由 xxx 发布
```

## 3. 状态定义

| 状态 | 广场页判定 | 详情页判定 | 表现 |
| --- | --- | --- | --- |
| loading | `status='loading'` 且无已加载数据 | 进入页面后首次请求中 | 骨架屏 / 加载块，不显示错误文案 |
| ready | 请求成功 | 请求成功 | 正常内容 |
| empty | `status='ready'` 且 `items.length=0` | — | 空状态 + 刷新 |
| error | 请求 reject 且非 404 | 请求 reject 且非 404 | 错误原因 + 重试 |
| notfound | — | HTTP 404 或 `id` 非正整数 | “动态不存在或已删除” + 返回广场 |
| loadingMore | 触底请求中 | — | 底部提示，不影响已有卡片 |
| loadMoreError | 触底请求失败 | — | 底部“点击重试”，不清空列表 |

## 4. 请求与并发策略

1. 每个列表版本持有一个自增 `requestToken`；刷新 / 重新加载时自增。
2. 响应返回后先比对令牌，不一致直接丢弃（`if (token !== requestToken) return`），防止“旧请求覆盖新筛选”。
3. 触底分页复用当前令牌：若期间发生刷新，分页结果作废，避免把旧列表的下一页拼到新列表上。
4. `hasMore = 已加载数量 < total && 本页非空`，两个条件同时满足才继续请求，避免空页死循环。
5. 错误统一在 `api/errors.ts` 归一为 `network / timeout / http / business` 四类，页面只消费文案，不直接读 `errMsg`。

## 5. 字段与界面映射（对齐 M02 契约）

| 契约字段 | 广场卡片 | 详情页 |
| --- | --- | --- |

| `media[].type` | 图片/视频标签、视频播放角标 | 大尺寸占位，1/2/3 列自适应 |

| `id` | 列表 key、跳转参数 | 页头 `#id`、路由校验 |
